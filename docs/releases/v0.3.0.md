## Highlights

Phase 1 is **feature-complete for sheets + transcript**, fully **open-source-first**, **local-only**, **no billing**, **no LLM required** for basic flow. The agent can now:
- Poll a Google Sheet with **exact 12-column** schema (`A:L`), validate `YouTube Link`, fetch transcript via **free** `youtube-transcript-api` → `yt-dlp` fallback, save to `output/transcripts/<video_id>.{txt,json}`, and update the sheet **sheet-safely** (`TRANSCRIPT_DONE` + `Transcript Link` only when valid; otherwise `TRANSCRIPT_FAILED` + `Error` + `Updated At` IST).

All 3 entrypoints validated dry-run → live:
- `python scripts/test_sheet.py --dry-run` / `--test-sheet`
- `python -m src.transcript --test-empty/--test-invalid --url` + `python tests/test_transcript.py` (6 offline cases)
- `python scripts/run_transcripts.py --dry-run` / `--limit 1` + `python main.py --run-transcripts --dry-run` (idempotent, no spurious writes)

## Known Limitations (v0.3.0)

| Limitation | Detail | Workaround |
|------------|--------|------------|
| **YouTube 429 Too Many Requests** | `youtube_transcript_api: 429 Client Error: Too Many Requests for url: https://www.youtube.com/api/timedtext...` + `yt-dlp: HTTP Error 429: Too Many Requests` — transient **IP rate-limit, not a code bug**. Observed on TED/TED-Ed `Ks-_Mh1QhMc`, `8S0FDjFBj8o`, `UF8uR6Z6KLc`, etc. `BaW_jenozKc` → `No video formats found`, `Ks-_Mh1QhMc` → `Subtitles are disabled` variant | Code correctly → `TRANSCRIPT_FAILED` + `Error=[TranscriptFetchError] ... 429` + `Updated At IST`, **no** `Transcript Link` overwrite. Retry after backoff, reduce `POLL_INTERVAL_SECONDS` (60), try different IP/video, or use `faster-whisper` offline (roadmap). Mock `TEDDEMO1234` (3000 chars/500 words) proves local save path offline. |
| Captions disabled / private | `TranscriptNotFoundError` / `Subtitles are disabled` | Use caption-enabled video |
| `yt-dlp` Python 3.10 deprecation | `Deprecated Feature: Support for Python 3.10 has been deprecated` | Upgrade to Python 3.11+ (functionality unaffected) |
| Quota / truncation | `update_cell` per field (3/row), `MAX_TRANSCRIPT_CHARS=12000` truncates at `।`/./!/ ? `>0.7` | Within 300/min quota; future `batch_update`, full save before truncate |
| No script/TTS/Drive in this release | Phase 1 is sheets + transcript only | Roadmap Phase 2: rule-based Telugu script → Piper/AI4Bharat → `pydub` MP3 → Drive `Audio Link` |

## Installation & Quickstart (v0.3.0)

```powershell
cd D:\Telugu_podcast_agent
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env; notepad .env  # set GOOGLE_SHEET_URL, GOOGLE_CREDENTIALS_FILE
# Sheet: 12-col header A1:L1 (ID … Updated At), Share sheet with service account email → Editor
python scripts/test_sheet.py --dry-run          # sheet connection
python tests/test_transcript.py                 # transcript validation
python scripts/run_transcripts.py --dry-run     # preview (no sheet write)
python scripts/run_transcripts.py --limit 1     # live (writes Status/Transcript Link/Error/Updated At)
```
